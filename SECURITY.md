# Segnalazioni di sicurezza

Non inserire token, credenziali, dati personali o dettagli sfruttabili in issue
pubbliche. Il proprietario deve abilitare il canale di segnalazione privata del
repository e assegnare un referente prima di invitare tester esterni.
Per ora il progetto è una foundation non distribuita; nessun indirizzo di
segnalazione è stato inventato o associato al proprietario.
